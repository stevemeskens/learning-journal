# Pomodoro Timer

A simple yet effective Pomodoro timer built with vanilla JavaScript.

## Features

- ⏱️ 25-minute work timer
- ⏸️ Pause/Resume functionality
- 🔄 Reset button
- 📊 Session counter
- 🔔 Audio notification on completion
- 📱 Responsive design

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## How to Use

1. Click Start to begin the timer
2. Click Pause to pause
3. Click Reset to go back to 25:00
